This plugin implements PayPal as a redirection payment method using the PayPal Orders API.

Flow:
- During checkout, the customer selects PayPal as the payment method.
- On order placement, the plugin creates a PayPal order and redirects the customer to PayPal to approve the payment.
- After approval, PayPal redirects the customer back to the store, where the plugin captures the PayPal order and marks the nopCommerce order as paid.

Configuration:
- Configure the plugin in the admin area (Configuration → Local plugins → PayPal → Configure).
- Provide PayPal REST API Client ID and Client Secret.
- Choose whether to use the PayPal sandbox environment.
- Optionally configure an additional fee (fixed or percentage).

Enabling/disabling:
- The plugin can be installed/uninstalled and enabled/disabled like any other payment plugin.
- Activation is controlled via the standard payment method settings (ActivePaymentMethodSystemNames).
